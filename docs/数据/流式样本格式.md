# OneRec 流式样本格式说明

本文档详细说明 OneRec 项目中流式训练样本的数据格式和处理流程。

---

## 样本格式总览

数据格式：**CSV（逗号分隔）**
- 字段数：**132 个字段**（f001.sign ~ f131.vfmodel）
- 分隔符：`,`（逗号）
- 序列内分隔符：`|`（竖线）
- 压缩格式：gzip

---

## 完整示例

### 简化的可读格式

```
sign=360_97286759
uid=user_abc123
target_url=1423 89 1567          # ← 模型要预测这个（Decoder 目标）
duration=45.0
logsess=url1|url2|...|url30      # ← 最近看了什么（Encoder 输入）
logqueue=url_a|url_b|...         # ← 更早看了什么（Encoder 输入）
logreallike=url_x|url_y|...      # ← 点赞过什么（Encoder 输入）
is_finish=1
is_like=1
...
```

### 实际 CSV 格式（节选关键字段）

```csv
360_97286759,scene_1,user_abc123,1423 89 1567,45.0,...,url1|url2|...|url30,...,url_a|url_b|...,...,url_x|url_y|...,1,1,0,...
```

**说明**：
- 第1列：`f001.sign` = `360_97286759`
- 第2列：`f002.scene` = `scene_1`
- 第3列：`f003.uid` = `user_abc123`
- 第4列：`f004.url` = `1423 89 1567`（目标视频的 Semantic ID）
- 第5列：`f005.duration` = `45.0`
- ...（中间省略）...
- `f044.logsess_item_seqs` = `url1|url2|...|url30`
- ...（中间省略）...
- `f029.like` = `1`

## 样本处理流程

```
原始 CSV 字符串（gzip 压缩）
        │
        ▼
按逗号分割 → 132 个字段数组
        │
        ▼
PtParser.parse() 处理：
        │
        ├─→ logsess_item_seqs: "url1|url2|..."
        │         │
        │         ▼
        │   按 "|" 分割 → 取最近 30 个 → 反转（时间序）
        │         │
        │         ▼
        │   url_tokenizer.seq_encode() → 每个 url 转 3 个 Token ID
        │         │
        │         ▼
        │   shape: [batch, 30, 3] 的 lmcode
        │
        ├─→ target url: "1423 89 1567"
        │         │
        │         ▼
        │   batch_encode(add_bos=True) → [BOS, 1423, 89, 1567]
        │         │
        │         ▼
        │   作为 Decoder 的 target
        │
        └─→ 其他特征：分桶、哈希、转 tensor
```

---

## 关键设计

| 设计点 | 说明 |
|--------|------|
| **序列反转** | `split_arr[::-1]` 把时间最近的放后面（符合 Transformer 位置编码习惯）|
| **填充 30 个** | 每个序列固定 30 个位置，不足补 `url_pad` |
| **mask 处理** | `logsess_mask` 标记哪些是真实数据、哪些是填充（1表示有效，0表示填充）|
| **负样本构造** | `expand_neg()` 把正样本的 URL 和特征打乱配对构造负样本 |
| **分桶处理** | 连续特征（如 duration、dwell）分桶转为离散 ID |
| **哈希处理** | 字符串 ID（如 uid、url）哈希后取模转为离散 ID |

## 数据文件位置

根据 `arguments/data_args.py` 配置：

```python
root_dir: str = "/mnt_onerec_model/corpus/video.rank.s101.pos_neg"
corpus_days: int = 2
compress_type: str = "gzip"
```

**目录结构示例**：
```
/mnt_onerec_model/corpus/video.rank.s101.pos_neg/
├── 20250101/
│   ├── part-00001.gz
│   ├── part-00002.gz
│   └── ...
├── 20250102/
│   ├── part-00001.gz
│   └── ...
└── ...
```

**文件格式**：
- 每个 `.gz` 文件包含多条 CSV 记录
- 每行是一条完整的训练样本（132 个字段）
- 使用 gzip 压缩节省存储

## 字段配置详情

完整的 132 个字段定义见 `arguments/data_args.py` 中的 `columns_def`：

```python
columns_def = [
    ('f001.sign', "", 1),           # 场景标识
    ('f003.uid', "", 1),            # 用户ID
    ('f004.url', "", 1),            # 目标视频URL（Semantic ID）
    ('f005.duration', "0", 1),      # 视频时长
    ...
    ('f044.logsess_item_seqs', "", 1),  # 短时行为序列
    ...
]
```

**元组含义**：`(字段名, 默认值, 是否用于 reward 阶段)`
