## 第二阶段：理解核心算法 (30分钟)

### 2. 阅读 rq_kmeans.py
**位置**: `src/rq_kmeans.py`

**功能**: 离线训练三层残差量化器

**学习重点**:
| 函数 | 功能 | 关键代码行 |
|------|------|-----------|
| `read_embeddings_hdf5()` | 数据读取 + HDF5缓存 | 18-81行 |
| `hierarchical_clustering_large()` | 三层迭代聚类 | 83-193行 |
| `convert_results_to_text()` | 结果格式转换 | 195-206行 |

**核心算法流程** (建议跟着代码画一遍):
```
原始数据 X
    ↓
[第1轮 MiniBatchKMeans] → 中心 C1, 标签 L1
    ↓
计算残差: R1 = X - C1[L1]
    ↓
[第2轮 MiniBatchKMeans] → 中心 C2, 标签 L2
    ↓
计算残差: R2 = R1 - C2[L2]
    ↓
[第3轮 MiniBatchKMeans] → 中心 C3, 标签 L3
```

**思考问题**:
- 为什么要用 `partial_fit` 分批训练？
- 为什么要做 shuffle 后再 fit 一遍？
- 残差是如何计算的？

### 3. 阅读 upload_new.py
**位置**: `src/upload_new.py`

**功能**: 增量更新 - 为新视频分配已有聚类中心

**学习重点**:
| 函数 | 功能 | 关键代码行 |
|------|------|-----------|
| `copy_if_different_size()` | 检查远端数据是否有更新 | 17-44行 |
| `load_existing_results()` | 加载已有聚类结果 | 46-63行 |
| `load_cluster_centers()` | 加载3层聚类中心 | 65-86行 |
| `predict_new_embeddings()` | 核心分配逻辑 | 88-153行 |

**关键逻辑** (第3层为什么用轮询？):
```python
# 第1、2层：找最近中心 (最近邻)
if j < 2:
    closest_idx = np.argmin(distances)
else:
    # 第3层：轮询分配 (负载均衡)
    key = '{}_{}'.format(labels[0], labels[1])
    cur_cnt = existing_md5s_l3cnt.get(key, 0)
    closest_idx = cur_cnt % 1500
    existing_md5s_l3cnt[key] = cur_cnt + 1
```

**思考问题**:
- 为什么要区分"已有MD5"和"新MD5"？
- 轮询分配如何解决长尾问题？
- `existing_md5s_l3cnt` 这个计数器的作用是什么？

## 第三阶段：理解数据分析 (20分钟)

### 4. 阅读 tde_analysis.py
**位置**: `analysis/tde_analysis.py`

**功能**: 计算 Token Distribution Entropy (分布熵)

**学习重点**:
- 理解什么是信息熵 (Entropy)
- 熵占比 (Entropy Ratio) 的意义
- 如何用熵评估聚类均衡性

**关键公式**:
```
Entropy = -Σ(p_i × log2(p_i))
Max_Entropy = log2(K)  # K是聚类中心数
Entropy_Ratio = Entropy / Max_Entropy
```

**输出解读**:
- 熵占比 > 90%: 分布很均衡 ✅
- 熵占比 < 70%: 分布不均，需要优化 ⚠️

- 为什么覆盖率通常很低？这有问题吗？

**关键指标**:
```
Coverage_Ratio = 实际唯一组合数 / 1500³
```

---

### 6. 阅读 recon_loss_ana.py
**位置**: `analysis/recon_loss_ana.py`

**功能**: 计算重建误差 (MSE)

**学习重点**:
- 理解重建过程: `X' = C1 + C2 + C3`
- 理解 MSE: `MSE = mean((X - X')²)`
- 如何用MSE评估量化质量

**关键流程**:
```
对每个MD5:
    1. 获取原始向量 X
    2. 获取3个聚类ID
    3. 查找对应聚类中心 C1, C2, C3
    4. 重建向量 X' = C1 + C2 + C3
    5. 计算 MSE(X, X')
```
