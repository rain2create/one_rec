# One-Rec Loss总结

## 一、Loss 计算流程图

### 1.1 整体Loss计算流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│ Decoder输出                                                              │
│ - output_logits: [B, 3, V]  每层码本的预测logits                         │
│ - labels: [B, 3] = [code1, code2, code3]                                │
│ - advantages: [B]  用户反馈权重                                          │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
┌───────────────────────────────────┐ ┌───────────────────────────────────┐
│ 对比学习 Loss (Token级别)          │ │ RL Loss (序列级别)                 │
│                                   │ │                                   │
│ loss = CrossEntropy(logits, label)│ │ probs = P(c1)*P(c2)*P(c3)        │
│      本质就为NTP loss                │ │ loss = -(ratio * advantages)      │
│ ┌─────────────────────────────┐   │ │                                   │
│ │ advantages > 0 (正样本)      │   │ │ ┌─────────────────────────────┐   │
│ │   → loss = -log(p) 提高     │   │ │ │ advantages > 0 (正样本)      │   │
│ │                             │   │ │ │   → 提高整个URL概率          │   │
│ │ advantages == 0 (中性样本)   │   │ │ │                             │   │
│ │   → loss = -log(1-p) 降低   │   │ │ │ advantages < 0 (负样本)      │   │
│ │                             │   │ │ │   → 降低整个URL概率          │   │
│ │ advantages < 0 (负样本)      │   │ │ │                             │   │
│ │   → 不参与                   │   │ │ │ advantages == 0 (中性样本)   │   │
│ └─────────────────────────────┘   │ │ │   → 不参与                   │   │
│                                   │ │ └─────────────────────────────┘   │
└───────────────────────────────────┘ └───────────────────────────────────┘
                    │                               │
                    └───────────────┬───────────────┘
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ MOE Aux Loss                                                            │
│ L_aux = n_experts × Σ(importance × fraction)                            │
│ 目的: 负载均衡，让各专家被均匀使用                                        │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ Total Loss = 对比学习Loss + RL Loss + 0.01 × MOE Aux Loss               │
└─────────────────────────────────────────────────────────────────────────┘
```

## 二、为什么这样构造 Loss？

### 2.1 核心问题：负样本为什么不参与对比学习？

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 业务场景分析                                                             │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  正样本: 用户看完视频30s，点了赞                                          │
│  负样本: 用户看完视频28s，点了"不喜欢"或skip                               │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ 两者的区别:                                                      │   │
│  │ - 视频内容可能相同 → 特征几乎一样                                     │   │
│  │ - 用户行为差异 → 仅在最后几秒的决策                               │   │
│  │ - 用户可能知识看烦了点跳过 不代表就真不喜欢                             │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 如果负样本参与对比学习会发生什么？                                         │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  正样本特征: [用户A, 视频X, 时长30s] → 目标: 提高概率                      │
│  负样本特征: [用户A, 视频X, 时长28s] → 目标: 降低概率                      │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ 问题:                                                            │   │
│  │   特征几乎一样 + 目标相反 = 模型困惑 = Loss震荡不收敛              │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 解决方案                                                                 │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  负样本只用 RL Loss:                                                     │
│  - 不直接干预token级别的预测                                             │
│  - 通过advantages调整整个序列概率                                        │
│  - 更"温和"，不会导致特征空间混乱                                         │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.2 中性样本为什么不参与RL？

```
中性样本: 用户看了视频，没有明确反馈（既没点赞也没不喜欢）

处理方式:
  - 对比学习: -log(1-p) 降低目标概率 ("不要太推荐"，不是"强烈不推荐")
  - RL Loss:  不参与 (保留探索空间，避免过度惩罚)

原因: 用户行为是"被动"的，可能是忘了点，也可能真不喜欢，RL 强制降低可能误伤
```

### 2.3 Loss分工总结

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 对比学习 (Token级别监督)                                                 │
├─────────────────────────────────────────────────────────────────────────┤
│ 正样本   → 学"什么是好的"    → 提高目标token概率 (-log(p))     让模型输出与label相近  │
│ 中性样本  → 学"什么是普通的"  → 降低目标token概率 (-log(1-p))  让模型输出与label 远离 │
│ 负样本   → 不参与            → (特征与正样本太接近)                        │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ RL Loss (序列级别强化)                                                   │
├─────────────────────────────────────────────────────────────────────────┤
│ 正样本   → 强化"生成这类URL"  → 提高整体序列概率                          │
│ 中性样本  → 不参与            → (反馈不明确)                              │
│ 负样本   → 强化"避免这类URL"  → 降低整体序列概率                          │
└─────────────────────────────────────────────────────────────────────────┘
```

## 三、RL Loss 算法细节

### 3.1 序列概率计算

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 从 Token概率 到 序列概率                                                 │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Decoder输出: logits [B, 3, V]                                          │
│       │                                                                 │
│       ▼                                                                 │
│  log_softmax → log P(c1), log P(c2), log P(c3)                          │
│       │                                                                 │
│       ▼                                                                 │
│  gather对应label → [log P(c1), log P(c2), log P(c3)]                    │
│       │                                                                 │
│       ▼                                                                 │
│  sum(dim=-1) → log P(c1) + log P(c2) + log P(c3)                        │
│       │                                                                 │
│       ▼                                                                 │
│  exp → P(序列) = P(c1) × P(c2) × P(c3)                                  │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ 数学推导:                                                         │   │
│  │   log P(序列) = log[P(c1)×P(c2)×P(c3)]                            │   │
│  │               = log P(c1) + log P(c2) + log P(c3)                 │   │
│  │   P(序列) = exp(log P(c1) + log P(c2) + log P(c3))                │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.2 当前实现的 RL Loss

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 代码实现 (decoder.py)                                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  pi_new = P(c1) × P(c2) × P(c3)      # 序列概率                         │
│                                                                         │
│  pi_safe = pi_new                     # 数值相等                        │
│                                                                         │
│  ratio = pi_new / pi_safe.detach()   # 数值=1, 但pi_new参与梯度计算      │
│                                        # pi_safe 不参与梯度回传，当作常熟 │
│  loss = -(ratio × advantages)                                           │
│       = -(pi_new / pi_new.detach() × advantages)                        │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.3 为什么要除 pi_safe (梯度分析)

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 梯度计算                                                                 │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  loss = -(pi_new / pi_new.detach()) × A                                 │
│                                                                         │
│  其中:                                                                   │
│    pi_new      → 参与梯度计算                                           │
│    pi_new.detach() → 不参与梯度计算 (视为常数)                           │
│                                                                         │
│  梯度:                                                                   │
│    d(loss)/d(pi_new) = -A × d(ratio)/d(pi_new)                          │
│                      = -A × (1 / pi_new.detach())                       │
│                      = -A / pi_new                                      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ 梯度缩放效果: 梯度被 1/pi_new 放大                                        │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  pi_new = 0.01  →  梯度放大 100 倍                                       │
│  pi_new = 0.1   →  梯度放大 10 倍                                        │
│  pi_new = 0.5   →  梯度放大 2 倍                                         │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ 效果:                                                             │   │
│  │   概率小的样本 → 梯度大 → 更新力度大                               │   │
│  │   概率大的样本 → 梯度小 → 更新力度小                               │   │
│  │                                                                   │   │
│  │ 直觉:                                                             │   │
│  │   模型预测得不好 (pi_new小) → 给更大的梯度去修正                   │   │
│  │   模型已经预测得好 (pi_new大) → 只需微调                           │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.4 梯度传导过程

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 完整梯度传导链路                                                         │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  pi_new = P(c1) × P(c2) × P(c3)                                         │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ 梯度对 P(c1):                                                    │   │
│  │   d(pi_new)/d(P(c1)) = P(c2) × P(c3)                             │   │
│  │   d(loss)/d(P(c1)) = -A/pi_new × P(c2)×P(c3)                     │   │
│  │                    = -A × P(c2)×P(c3) / (P(c1)×P(c2)×P(c3))       │   │
│  │                    = -A / P(c1)                                   │   │
│  │                                                                   │   │
│  │ 同理 P(c2), P(c3):                                               │   │
│  │   d(loss)/d(P(ci)) = -A / P(ci)                                  │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  最终传导到 logits:                                                      │
│    d(loss)/d(logits) = d(loss)/d(P) × d(P)/d(logits)                    │
│                      = (-A/P) × softmax梯度                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.5 有 Clip vs 无 Clip 对比

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 无 Clip (当前实现)                                                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  loss = -(pi_new / pi_new.detach()) × A                                 │
│       = -A × (pi_new / pi_new)           # 数值上                       │
│                                                                         │
│  梯度 = -A / pi_new                                                      │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ 特点:                                                             │   │
│  │   - 梯度可能非常大 (当pi_new很小时)                                │   │
│  │   - 更新不稳定，可能震荡                                           │   │
│  │   - 简单直接，实现方便                                             │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 有 Clip (PPO标准实现)                                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ratio = pi_new / pi_old              # pi_old是旧策略概率, 固定不变     │
│                                                                         │
│  loss = -min(ratio × A, clip(ratio, 1-ε, 1+ε) × A)                      │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ 梯度 (未被clip时):                                                │   │
│  │   d(loss)/d(pi_new) = -A / pi_old                                 │   │
│  │                                                                   │   │
│  │ 梯度 (被clip时):                                                  │   │
│  │   d(loss)/d(pi_new) = 0                                           │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ 特点:                                                             │   │
│  │   - 梯度被 pi_old 归一化, 更稳定                                   │   │
│  │   - clip限制单次更新步长                                          │   │
│  │   - ratio变化超过(1±ε)就停止梯度                                  │   │
│  │   - 训练更稳定, 但需要存储pi_old                                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```
