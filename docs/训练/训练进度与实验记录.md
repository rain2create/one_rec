# One-Rec 实验记录与训练过程

## 1. 训练配置

### 1.1 初始训练配置（30天语料）

| 配置项 | 数值 | 说明 |
|--------|------|------|
| **语料天数** | 30 天 | 首次训练使用一个月数据 |
| **原始样本** | 2.16 亿条 | 720万/天 × 30天 |
| **过滤后样本** | 7,130 万条 | check_line 保留约 33% |

| 配置项 | 数值 | 说明 |
|--------|------|------|
| **Batch Size** | 1024 | 每步处理样本数 |
| **Learning Rate (dense)** | 2e-4 | 稠密参数学习率 |
| **Learning Rate (sparse)** | 6e-2 | 稀疏参数学习率 |

| **Logging Steps** | 100 | 每100步打印日志 |
| **Save Steps** | 10,000 | 每1万步保存checkpoint |

**注**：以上"过滤后"和"expand_neg后"为实际参与训练的样本数

### 2.3 样本流转计算详情

```
【原始数据 → 实际训练样本】

Step 1: 原始数据（每天）
    480文件 × 15,000条 = 720万条
    
Step 2: check_line过滤（保留33%）
    720万 × 0.33 = 238万条
    
Step 3: 实际加载（增量训练）
    由于滑动窗口和done标记
    实际每天加载约491万条原始样本
    对应过滤后：491万 × 0.33 = 162万条
    
Step 4: expand_neg扩充（×1.47）
    162万 × 1.47 = 238万条
    
Step 5: 进入模型训练
    每步处理：1024 × 1.55 = 1,587条
    每天步数：238万 ÷ 1,587 ≈ 1,500步

【关键数字】
    原始数据：491万条/天
    过滤后：  162万条/天（33%保留率）
    expand_neg后：238万条/天（实际进入模型）
```
