## 2. 各模块详解

### 2.1 SparseModel（稀疏特征层）

**作用**：将离散的类别特征（用户ID、视频标签等）映射为稠密向量。

**核心特点**：
- 使用 `sparse=True` 的 Embedding，支持千万级稀疏特征
- 单独使用 SparseAdam 优化器，节省内存

**特征Embedding表**：

| 特征名 | 词典大小 | 输出维度 | 说明 |
|--------|---------|---------|------|
| sign | 4 | 128 | 场景标识 |
| autok | 11 | 128 | 自动播放计数 |
| autoplay | 3 | 128 | 是否自动播放 |
| reqtimes | 30 | 128 | 请求次数分桶 |
| qid | 1,000,003 | 128 | 作者ID |
| videotag | 10,007 | 128 | 视频标签 |
| timegap | 30 | 128 | 时间间隔分桶 |
| duration | 30 | 128 | 视频时长分桶 |
| dwell | 30 | 128 | 观看时长分桶 |
| label | 100,019 | 128 | 交互标签 |
| codebook_0/1/2 | 1,502 | 128 | 语义ID码本 |

**输出格式**：
```python
[
    user_features,        # [batch, 4*128=512]
    logsess_features,     # [batch, 30, 7*128=896]
    logqueue_features,    # [batch, 30, 7*128=896]
    logreallike_features  # [batch, 30, 4*128=512]
]
```

---

### 2.2 Encoder（Transformer编码器）

**作用**：将用户的多组行为序列编码为统一的上下文表示。

**结构**：
```
┌─────────────────────────────────────────┐
│           Encoder结构                   │
├─────────────────────────────────────────┤
│                                         │
│  输入：4组Embedding                      │
│    ├─ user: [B, 512]                   │
│    ├─ logsess: [B, 30, 896]            │
│    ├─ logque: [B, 30, 896]             │
│    └─ logreallike: [B, 30, 512]        │
│                                         │
│  投影层（每组独立）：                     │
│    Linear(512 → 256)                    │
│    Linear(896 → 256)                    │
│    Linear(896 → 256)                    │
│    Linear(512 → 256)                    │
│                                         │
│  拼接序列：[B, 1+30+30+30, 256]          │
│    [CLS] + 短时行为 + 长时行为 + 正反馈   │
│                                         │
│  输出：[B, 91, 256]                     │
│    每个位置代表一个用户特征/行为item的    │
│    上下文感知表示                        │
│                                         │
└─────────────────────────────────────────┘
```

**关键设计**：
- 用户静态特征作为 [CLS] token 放在序列开头
- 位置编码让模型感知序列顺序
- 使用 Transformer 的自注意力机制建模行为间的关系

---

### 2.3 Decoder（自回归解码器）

**作用**：根据用户上下文表示，自回归生成目标视频的语义ID。

**核心结构**：
```
┌─────────────────────────────────────────┐
│           Decoder结构                   │
├─────────────────────────────────────────┤
│                                         │
│  输入：                                  │
│    ├─ 上下文表示 [B, 91, 256]            │
│    └─ BOS起始符 [B, 1]                   │
│                                         │
│  自回归生成过程：                         │
│    ┌─────────────────────────────────┐  │
│    │ Step 1: 输入 [BOS]              │  │
│    │        ↓                        │  │
│    │        DecoderMOE               │  │
│    │        ↓                        │  │
│    │        输出层0                  │  │
│    │        ↓                        │  │
│    │        Softmax → 预测 tok_1     │  │
│    │        [0~1500]                 │  │
│    └────────┬────────────────────────┘  │
│             │                           │
│    ┌────────▼────────────────────────┐  │
│    │ Step 2: 输入 [BOS, tok_1]       │  │
│    │        ↓                        │  │
│    │        DecoderMOE               │  │
│    │        ↓                        │  │
│    │        输出层1                  │  │
│    │        ↓                        │  │
│    │        Softmax → 预测 tok_2     │  │
│    │        [0~1500]                 │  │
│    └────────┬────────────────────────┘  │
│             │                           │
│    ┌────────▼────────────────────────┐  │
│    │ Step 3: 输入 [BOS, tok_1, tok_2]│  │
│    │        ↓                        │  │
│    │        DecoderMOE               │  │
│    │        ↓                        │  │
│    │        输出层2                  │  │
│    │        ↓                        │  │
│    │        Softmax → 预测 tok_3     │  │
│    │        [0~1500]                 │  │
│    └─────────────────────────────────┘  │
│                                         │
│  输出：[tok_1, tok_2, tok_3] = 语义ID   │
│                                         │
└─────────────────────────────────────────┘
```

**DecoderMOE（混合专家网络）**：
- 24 个专家网络（MLP）
- 每层选择 top-2 专家参与计算
- 负载均衡损失确保专家利用率均匀

**输出层**：
- 3层独立的 Linear 层（与 Embedding 权重共享）
- 每层输出维度：1502（1500码本 + BOS + UNK）

## 3. 推理流程（Beam Search生成）

```
┌─────────────────────────────────────────────────────────────────┐
│                     推理阶段数据流                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  输入：用户历史行为特征                                           │
│       ↓                                                          │
│  SparseModel → 4组Embedding                                      │
│       ↓                                                          │
│  Encoder → 上下文表示 [B, 91, 256]                               │
│       ↓                                                          │
│  Decoder.bs_rl_generate()                                        │
│       │                                                          │
│       ├─ Beam Search（group_num=5）                              │
│       │   每层保留 top-5 候选                                    │
│       │                                                          │
│       ├─ 确保码本有效性（ensure_matrix）                          │
│       │   保证生成的 [tok1,tok2,tok3] 是码本中存在的视频           │
│       │                                                          │
│       └─ 输出：5 个候选视频                                      │
│               [url_1, url_2, url_3, url_4, url_5]                │
│               按生成概率排序                                      │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 4. 模型参数统计

| 模块 | 参数量 | 说明 |

## 5. 关键创新点

1. **语义ID生成**：将推荐问题转化为Seq2Seq生成问题
2. **分层码本**：3层×1500的层次化语义表示
3. **MoE架构**：Decoder使用24专家提升容量
4. **多行为序列**：融合短时/长时/正反馈三种行为
