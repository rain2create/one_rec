# RQ-KMeans 训练流程详解

本文档详细说明 RQ-KMeans 训练阶段的数据流程和核心机制。

---

## 核心概念

**关键理解**：所有样本共享同一套聚类中心，不是每个样本有自己的中心。

| 问题 | 答案 |
|------|------|
| 聚类中心是共享的吗？ | 是的！所有1500个中心是全局共享的 |
| 每个样本有自己的中心吗？ | 不是！样本只是被分配到某个共享中心 |
| 残差怎么组织？ | 所有样本的残差组成新数据集，再做KMeans |
| 为什么叫残差量化？ | 每层量化误差成为下层的输入，层层精修 |

---

## 训练阶段数据流程图

```
输入: N个样本的嵌入向量 (比如 100万个视频，每个64维)

   样本1:  [0.5, -0.3, 0.8, ..., 0.2]  --
   样本2:  [0.2, 0.1, -0.5, ..., 0.3]  --|--- 100万个64维向量
   样本3:  [-0.1, 0.4, 0.2, ..., -0.1] --|
   ...                                  |
   样本N:  [0.3, -0.2, 0.1, ..., 0.5]  --
                   |
                   v
+-------------------------------------------------------------------+
|  【第1轮聚类】对所有N个样本做MiniBatchKMeans                        |
|                                                                   |
|   KMeans(X, n_clusters=1500)                                      |
|        |                                                          |
|        v                                                          |
|   输出: 1500个共享聚类中心 C1[0..1499]                              |
|         (每个中心都是64维向量)                                     |
|                                                                   |
|   同时得到每个样本的标签:                                           |
|   样本1 -> 属于中心 #1423                                          |
|   样本2 -> 属于中心 #89                                            |
|   样本3 -> 属于中心 #1567                                          |
|   ...                                                             |
+-------------------------------------------------------------------+
                   |
                   v
+-------------------------------------------------------------------+
|  【计算第1层残差】每个样本减去自己所属的中心                         |
|                                                                   |
|   样本1的残差 R1_1 = X1 - C1[1423]                                 |
|   样本2的残差 R1_2 = X2 - C1[89]                                   |
|   样本3的残差 R1_3 = X3 - C1[1567]                                 |
|   ...                                                             |
|                                                                   |
|   关键：残差向量仍然是64维，但现在构成了新的数据集                    |
|   {R1_1, R1_2, R1_3, ..., R1_N} <- 还是N个样本，每个64维            |
+-------------------------------------------------------------------+
                   |
                   v
+-------------------------------------------------------------------+
|  【第2轮聚类】对所有N个残差向量做KMeans                              |
|                                                                   |
|   KMeans({R1_1, R1_2, ..., R1_N}, n_clusters=1500)                 |
|        |                                                          |
|        v                                                          |
|   输出: 1500个共享聚类中心 C2[0..1499]                              |
|         (还是64维，残差空间中的中心)                                |
|                                                                   |
|   样本1的残差 -> 属于中心 C2[89]                                   |
|   样本2的残差 -> 属于中心 C2[1567]                                 |
|   ...                                                             |
+-------------------------------------------------------------------+
                   |
                   v
+-------------------------------------------------------------------+
|  【计算第2层残差】                                                 |
|                                                                   |
|   样本1: R2_1 = R1_1 - C2[89] = (X1-C1[1423]) - C2[89]             |
|   样本2: R2_2 = R1_2 - C2[1567] = (X2-C1[89]) - C2[1567]           |
|   ...                                                             |
|                                                                   |
|   新数据集: {R2_1, R2_2, ..., R2_N}                                 |
+-------------------------------------------------------------------+
                   |
                   v
+-------------------------------------------------------------------+
|  【第3轮聚类】                                                    |
|                                                                   |
|   KMeans({R2_1, R2_2, ..., R2_N}, n_clusters=1500)                |
|        |                                                          |
|        v                                                          |
|   输出: C3[0..1499]                                               |
+-------------------------------------------------------------------+
```

## 简化示例

假设只有 **3个样本**（2维向量，方便理解）：

```
原始数据:        第1轮聚类:           第1层残差:
+--------+      C1[0]=[0,0]          R1_1 = [10,10]-[0,0] = [10,10]
|[10,10] | -->  C1[1]=[10,10]  -->   R1_2 = [11,11]-[10,10] = [1,1]
|[11,11] | -->  (2个中心)             R1_3 = [-5,-5]-[0,0] = [-5,-5]
|[-5,-5] | -->
+--------+

第2轮聚类是对这些残差做:
  输入: {[10,10], [1,1], [-5,-5]} --> KMeans(n_clusters=2) 
  输出: C2[0]=[5.5,5.5], C2[1]=[-5,-5]
```

### 残差计算过程

```
样本1的完整流程:
  X1 = [10, 10]
  
  第1层: C1[1] = [10, 10]
         R1 = X1 - C1[1] = [0, 0]
         
  样本2 [11,11] -> 分配到 C1[1]=[10,10] -> R1 = [1,1]  
  样本3 [-5,-5] -> 分配到 C1[0]=[0,0]   -> R1 = [-5,-5]
  
  第2层对 {[0,0], [1,1], [-5,-5]} 做KMeans...
```

## 核心代码对照

### 第1轮训练（原始数据）

```python
# rq_kmeans.py:127-138
kmeans = MiniBatchKMeans(n_clusters=K, batch_size=batch_size, ...)

# 分批拟合模型
for i in tqdm(range(0, total_samples, batch_size), desc="聚类处理"):
    batch = X[i:i+batch_size]
    kmeans.partial_fit(batch)  # 在原始数据X上训练

# 预测聚类标签
cluster_labels = np.zeros(total_samples, dtype=np.uint16)
for i in tqdm(range(0, total_samples, batch_size), desc="标签预测"):
    batch = X[i:i+batch_size]
    labels = kmeans.predict(batch)
    cluster_labels[i:i+batch_size] = labels

# 获取聚类中心
cluster_centers = kmeans.cluster_centers_  # shape: (1500, 64)
```

### 计算残差（关键！）

```python
# rq_kmeans.py:185-190
for i in tqdm(range(0, total_samples, batch_size), desc="计算残差"):
    batch = X[i:i+batch_size]
    labels_batch = cluster_labels[i:i+batch_size]
    # 计算残差：当前向量减去聚类中心
    X[i:i+batch_size] = batch - cluster_centers[labels_batch]

# 注意：这里X被原地修改，变成了残差数据集！
# 下一轮KMeans在残差上训练
```

### 第2轮训练（残差数据）

```python
# 第2轮 - X现在已经是第1层的残差了
kmeans = MiniBatchKMeans(n_clusters=K, batch_size=batch_size, ...)

for i in tqdm(range(0, total_samples, batch_size), ...):
    batch = X[i:i+batch_size]  # 这是第1层的残差！
    kmeans.partial_fit(batch)

# 再次计算残差，进入第3轮...
```

---

## 关键设计要点

1. **共享中心**：每轮产生1500个全局共享的聚类中心
2. **残差传递**：每轮的输出（残差）是下轮的输入
3. **原地修改**：代码中X被原地修改，节省内存
4. **分层精修**：X ≈ C1 + C2 + C3，层层逼近原始向量

## 维度说明

| 变量 | 维度 | 说明 |
|------|------|------|
| X (原始数据) | (N, 64) | N个样本，每样本64维 |
| C1 | (1500, 64) | 第1层1500个中心 |
| R1 (残差) | (N, 64) | 第1层残差，仍64维 |
| C2 | (1500, 64) | 第2层1500个中心 |
| R2 (残差) | (N, 64) | 第2层残差 |
| C3 | (1500, 64) | 第3层1500个中心 |
