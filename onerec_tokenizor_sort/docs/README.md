## 核心概念: 残差量化

```
原始向量 X
    │
    ├──► 第1层聚类 ──► 中心 C1 ──► 量化误差 R1 = X - C1
    │                      │
    │                      ▼
    │              输出 Token1 (1~1500)
    │
    ├──► 第2层聚类 ──► 中心 C2 ──► 量化误差 R2 = R1 - C2
    │                      │
    │                      ▼
    │              输出 Token2 (1~1500)
    │
    └──► 第3层聚类 ──► 中心 C3
                           │
                           ▼
                   输出 Token3 (1~1500)

最终表示: X ≈ C1 + C2 + C3
          Token序列: [T1, T2, T3]
```

## 各模块详解

### 1. rq_kmeans.py - 离线训练

**功能**: 从零开始训练3层残差量化器

**输入**: `video_emb` (格式: MD5 + 64维向量)

**输出**:
- `clustering_results` - 每个视频的3层聚类ID
- `cluster_centers/round_*_centers.txt` - 每层1500个聚类中心

**关键参数**:
```python
K = 1500      # 每层聚类数
N = 3         # 层数
batch_size = 100000  # 批处理大小
```

---

### 2. upload_new.py - 在线增量

**功能**: 新视频增量分配Token，避免全量重训练

**核心逻辑**:
```
新视频向量
    │
    ▼
┌─────────────────┐
│ 第1层分配        │
│ • 计算到1500个中心距离
│ • 选最近中心 → Token1
│ • 残差 = 向量 - 中心1
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 第2层分配        │
│ • 残差到1500个中心距离
│ • 选最近中心 → Token2
│ • 残差 = 残差 - 中心2
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 第3层分配        │
│ • 按(l1_l2)计数器轮询
│ • 分配 → Token3
│ • 保证各桶均衡(解决长尾)
└────────┬────────┘
         │
         ▼
    追加到结果文件
```

**为什么第3层用轮询？**
- 经过两层残差后，第3层向量分布稀疏
- 最近中心会导致热门桶过度集中
- 轮询保证每个Token被均匀使用

---

### 3. 分析模块

| 模块 | 用途 | 核心指标 |
|------|------|----------|
| `recon_loss_ana.py` | 评估重建质量 | MSE = \|X - (C1+C2+C3)\|² |
| `cover_ana.py` | 检查ID空间利用率 | 唯一组合数 / 1500³ |
| `tde_analysis.py` | 评估分布均衡性 | Token Distribution Entropy |

## 数据格式说明

### 输入: video_emb
```
md5_1	0.12 0.34 0.56 ... 0.78  (64维)
md5_2	0.23 0.45 0.67 ... 0.89  (64维)
...
```

### 输出: clustering_results
```
md5_1	1423 89 1567
md5_2	56 1203 899
...
↑      ↑   ↑  ↑
MD5   L1  L2  L3
```

### 输出: round_X_centers.txt
```
cluster_index	cluster_size	center_vector
1	5234	0.12 0.34 0.56 ... 0.78
2	4891	0.23 0.45 0.67 ... 0.89
...
```

## 典型使用流程

```bash
# 1. 首次训练 (离线)
cd src

python recon_loss_ana.py   # 看MSE分布
```

## 关键设计决策

| 问题 | 解决方案 | 原因 |
|------|----------|------|
| 数据量大 | HDF5 + MiniBatchKMeans | 内存友好，支持亿级样本 |
| 增量更新 | 固定中心 + 轮询分配 | 避免模型漂移，保证均衡 |
| 重建精度 | 3层残差 | 平衡压缩率与精度 |
| 第3层长尾 | 轮询而非最近距离 | 避免某些Token过载 |
